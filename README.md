## 📌 About The Project

**Personal Expense Tracker** is a beginner-friendly web application developed to help users manage their daily expenses easily.

Users can record expense details, select categories, view their expense history, and calculate their total spending automatically. The application uses browser `localStorage` to preserve expense records after refreshing the page.

This project demonstrates the practical application of front-end web development technologies.

## ✨ Key Features

| Feature                    | Description                                                    |
| -------------------------- | -------------------------------------------------------------- |
| ➕ Add Expenses             | Record expenses with a name, amount, category, and date.       |
| 📋 View Expenses           | Display recorded expenses in an organized list.                |
| 🏷️ Categories             | Organize expenses into Food, Travel, Education, and Other.     |
| 💰 Total Calculation       | Calculate the total amount of recorded expenses automatically. |
| 🗑️ Delete Expenses        | Remove unwanted expense records.                               |
| 💾 Local Storage           | Preserve saved records after a normal page refresh.            |
| 🎨 User-Friendly Interface | Use a simple and clear interface to manage expenses.           |

## 🛠️ Built With

* **HTML5** — Structures the application.
* **CSS3** — Styles the interface and improves its appearance.
* **JavaScript** — Handles application functionality and user interactions.
* **Browser localStorage** — Stores expense records locally.

## 🚀 Getting Started

Follow these steps to run the application on your computer.

### Prerequisites

You need:

* A modern web browser.
* A code editor such as Visual Studio Code (optional).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

**2. Open the project folder**

```bash
cd Personal-Expense-Tracker
```

**3. Run the application**

Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension if you have it installed.

## 💡 How to Use

1. Open the application in your browser.
2. Enter the expense name and amount.
3. Select the appropriate category.
4. Enter the expense date.
5. Click **Add Expense**.
6. View your expense records in the list.
7. Check the automatically calculated total.
8. Delete an expense when necessary.

Your saved records should remain available after refreshing the page in the same browser and website origin.

## ⚠️ Current Limitations

* Expense records are stored locally in the browser.
* Clearing the browser's site data may remove saved records.
* The application does not currently include user authentication.
* Data is not automatically synchronized across devices.
* Monthly reports and spending charts are not currently available.
